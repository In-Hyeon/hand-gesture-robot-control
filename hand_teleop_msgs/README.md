# `/hand/state` 인터페이스 (v0.1 초안)

인식부(카메라 → 손 추적 → 떨림 필터 → 제스처 판별)와 제어부(명령 생성 → 안전 감시 → 로봇)를 잇는 **유일한 연결**이다.
두 파트는 이 메시지만 맞추면 따로 개발하고 테스트할 수 있다. 필드 정의는 [`msg/HandState.msg`](msg/HandState.msg)에 있다.

| 항목 | 값 |
|---|---|
| 토픽 | `/hand/state` |
| 타입 | `hand_teleop_msgs/msg/HandState` |
| 발행 주기 | 카메라 프레임마다(~30Hz). **손이 없어도 발행** |
| QoS | Reliable, KeepLast(1) |
| 발행 노드 | 인식 노드 1개 (손 좌표 + 제스처 판별이 같은 프로세스 안에 있음) |

## 필드 요약
| 필드 | 타입 | 뜻 |
|---|---|---|
| `header.stamp` | time | **카메라 프레임을 얻은 시각**(발행 시각이 아님). 종단 지연은 `로봇 반응 시각 - stamp` |
| `hand_detected` | bool | 추적 중인 손이 이번 프레임에 있는지 |
| `handedness` | uint8 | 0 모름 / 1 왼손 / 2 오른손 |
| `confidence` | float32 | 0~1. 손이 없으면 0 |
| `x`, `y` | float32 | 필터를 거친 손 기준점(손목과 손바닥 기저부의 평균). 영상 너비로 나눈 값 |
| `mode` | uint8 | 0 IDLE / 1 MOVE / 2 HEIGHT / 3 HOLD |
| `gripper` | uint8 | 0 OPEN / 1 CLOSE (목표 상태) |

## 역할 분담 (이 형식에서 정해지는 것)
**인식부가 하는 것**
- 클러치 상태 기계: 활성화와 정지 제스처를 0.5초 유지했는지 확인하고, 그 결과로 `mode`를 정한다.
- 일시정지: 손을 놓치거나 신뢰도가 기준 밑으로 떨어지면 `mode=IDLE`. 다시 움직이려면 활성화 제스처가 필요하다.
- 그리퍼 전환 중에는 `mode=HOLD`로 둬서 위치를 고정시킨다.
- 손이 여러 개 보이면 활성화한 손만 추적한다(좌우가 같고 직전 위치와 가장 가까운 손).
- 제스처 판별에는 **원본 랜드마크**를 쓴다. 필터는 지연을 더하고, 판별은 이미 5프레임 연속 규칙으로 안정화되기 때문이다. `x, y` 위치에만 필터를 쓴다.

**제어부가 하는 것**
- 클러치 기준 상대 매핑: `mode`가 IDLE/HOLD에서 MOVE나 HEIGHT로 바뀌는 순간, 그리고 MOVE와 HEIGHT 사이에서 바뀌는 순간마다 (손 x,y, 로봇 위치)를 기준점으로 잡는다. 그 뒤로는 `로봇 목표 = 로봇 기준점 + (손 - 손 기준점) × 배율`.
- 축 매핑과 방향 부호: 카메라 영상의 오른쪽(+x)이 로봇의 어느 방향인지는 설치 배치에 따라 달라지므로 파라미터로 둔다.
- 영상 좌표 → mm 배율, 작업 공간 클램핑, 속도 제한, IK.
- **통신 감시: `/hand/state`가 0.2초 동안 안 오면 일시정지.** 인식부는 손이 없어도 계속 발행하므로, 메시지가 끊겼다는 것은 인식부가 죽었다는 뜻이다.
- IDLE이나 HOLD 상태에서도 "현재 위치 유지" 명령을 30Hz로 계속 보낸다(로봇 워치독용).

## 좌표 규칙
- 원점은 영상 왼쪽 위. x는 오른쪽이 +, y는 아래쪽이 +. 좌우를 반전하지 않은 카메라 원본 기준이다.
- **두 축 모두 영상 너비로 나눈다.** 640×480이면 x는 0~1, y는 0~0.75다. 축마다 배율이 같아서 손으로 원을 그리면 원으로 전달된다. 해상도가 바뀌어도 값의 크기가 유지된다.
- 깊이(z)는 보내지 않는다. 웹캠 하나로는 깊이를 알 수 없어서, 높이는 HEIGHT 모드에서 y 변화량으로 조절한다.
- `hand_detected=false`일 때 `x, y`에는 마지막 값이 남아 있지만 쓰면 안 된다.

## 모드 전이 예시
```
IDLE ──(활성화 제스처 0.5초)──▶ MOVE ⇄ HEIGHT   (높이 제스처를 유지하는 동안 HEIGHT)
  ▲                              │ ▲
  │      (정지 후보 감지, 그리퍼 전환) │ │ (후보 사라짐, 전환 끝)
  │                              ▼ │
  └──(정지 0.5초 확인 / 손 소실)─── HOLD
```
- MOVE에서 정지 후보가 보이면 즉시 HOLD로 바꿔 위치를 고정하고, 0.5초 유지가 확인되면 IDLE로 간다. 후보가 사라지면 MOVE로 돌아간다(이때 기준점을 새로 잡는다).
- 손을 놓치거나 신뢰도가 떨어지면 어느 모드에서든 바로 IDLE로 간다.

## 정해지지 않은 것
- 활성화, 정지, 높이, 그리퍼에 각각 어떤 제스처를 쓸지 (제스처 판별 파트)
- `confidence` 일시정지 기준값 (기본 0.5로 시작해서 녹화 데이터를 보고 조정)
- 영상 좌표 → mm 배율 기본값 (명령 생성 파트)

cd ~/ros2_ws/src && ln -s <저장소 경로>/hand_teleop_msgs .
